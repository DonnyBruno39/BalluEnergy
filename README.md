# Ballu Energy 0.2.0

Android-приложение для Ballu Transformer DI 4.0.

В этой версии добавлен экран статистики с периодами:
1 минута / 10 минут / Час / День / Неделя / Месяц.

Есть график мощности и температуры, расход кВт·ч и стоимость.

Пока данные графика демонстрационные. Следующий этап — заменить их реальными
данными Hommyn/MQTT и сохранять историю локально.
